# 字幕与直播画面

字幕层是一个透明网页，作为浏览器源放进 OBS 或哔哩哔哩直播姬。它只做三件事：显示弹幕、显示游戏动作、显示 AI 说出口的话。

---

## 1. 字幕层的信息结构

最多同时 4 条卡片，从下往上排：

| 类型 | 颜色 | 内容来源 | 默认停留 |
| --- | --- | --- | --- |
| 弹幕 | 粉 `#fb7299` | WS `event`，`type=danmaku`，跳过测试事件 | 25 秒起 |
| 动作 | 青 `#5ad0e6` | WS `stardew_step`，或日志里的 `大肥鱼托管：…` | 进行中 20 秒起，结束 30 秒起 |
| 肥鱼 | 蓝 `#3d8bfd` | WS `speak`，即 AI 正在说的话 | 8 秒（跟随配置） |

配对成功后，弹幕和回复合成一组，整组停留 30 秒。

```text
┌─────────────────────────────┐
│ 弹幕  观众：你倒是买种子呀     │
│ 肥鱼  别催别催，这不就去了。   │
└─────────────────────────────┘
```

## 2. WebSocket 契约

页面连 `ws://<host>/ws`，断线 2 秒后自动重连。本实验用到的消息：

| `kind` | 关键字段 | 字幕层行为 |
| --- | --- | --- |
| `speak` | `text`, `id` | 加一条“肥鱼”卡；可能和上一条弹幕配对 |
| `reply` | `type`, `text`, `desc` | 记录“待配对回复”，不直接显示 |
| `event` | `type`, `desc`, `test` | `type=danmaku` 且非测试时显示弹幕卡 |
| `stardew_step` | `text` | 显示一条“动作”卡，过滤内部工具 |
| `log` | `level`, `msg` | 从 `[星露谷] … 大肥鱼托管：…` 提取本轮汇报 |
| `bye` | — | 清空字幕并隐藏页面 |

`reply` 不直接显示的原因：回复文本会在随后的 `speak` 里再出现一次，直接显示会重复；而且只有 `speak` 才代表“真的说出口”。

### 配对逻辑

```text
收到 reply(type=danmaku)      -> pendingReply = {text, at}
收到 speak(text)：
  if pendingReply 存在
     and pendingReply.text == speak.text
     and 25 秒内
     and 最近一条弹幕卡还在、没被用过
  -> 删除单独弹幕卡，创建 pair(弹幕, 回复)，30 秒后一起消失
  else
  -> 单独显示“肥鱼”卡
```

三个约束缺一不可：

1. **类型必须是 danmaku。** 礼物、进房、动作播报不参与配对。
2. **文本必须相同。** 只按时间配对会被紧挨着的游戏语音抢走。
3. **只保留一个待配对回复。** 多条弹幕同时进来时，宁可少配，也不要串台。

## 3. 动作字幕的过滤

模型每调一次工具都会产生一条步骤。直接显示会出现：

```text
Qoder move_to → (65,22)
Qoder wait
Qoder close_menu
```

观众不需要这些。字幕层维护一个隐藏集合，只显示结果型动作：

- 显示：浇水、收获、开垦、播种、清理、钓鱼、下矿、买卖、出货、送礼、睡觉、照顾动物、做饭、打怪、升级工具、建造、节日；
- 隐藏：等待、走路、前往、互动、对话、开关界面、商店点击、整理背包、查询信息、吃东西、制作、看委托板、使用工具；
- 地点翻成中文（`SeedShop` → `杂货店`，`UndergroundMine*` → `矿洞`）；
- 坐标直接删除；Markdown 去掉；长汇报按句拆成多行。

## 4. 直播姬 / OBS 设置

1. 添加“浏览器”源，地址填 `http://127.0.0.1:8787/overlay`；
2. 宽高建议 1280×360 到 1280×400，背景透明；
3. 放在游戏画面左下角，不要挡人物和 UI；
4. 先用 `?demo=1` 看四种卡片的样式和动画，正式源不要带 demo；
5. 改完字幕页面后刷新浏览器源（直播姬里右键 → 刷新）；
6. 页面支持 `file://`，所以也可以直接把 `overlay.html` 当本地文件源，避免依赖本地 HTTP 服务。

可选查询参数：

```text
?demo=1          循环播放示例内容
?lines=3         最多显示几条卡片（1–8）
?keep=10         单条卡片停留秒数
?host=127.0.0.1:8787   指定 WS 地址
```

## 5. 只改字幕时的热替换（临时手段）

WhaleTalk 是 one-file 打包，运行时会把 `web/` 解压到 `%TEMP%/_MEIxxxx/`。只改 CSS/JS 时，可以直接覆盖：

```text
%TEMP%/_MEIxxxx/web/overlay.html
```

然后刷新直播姬的浏览器源，不用重启 WhaleTalk。

注意：

- 这是**临时**的，进程重启后会回到打包时的版本；
- 只适合改样式、文案、配对逻辑这类前端改动；
- 改了 Python/WS 协议就必须重新打包。

## 6. 游戏窗口与 DPI

- 游戏客户区固定为 **1920×1080**，放在屏幕左上角 (0,0)；
- 4K + 150% 缩放下，DPI-unaware 截图是 2560×1440，和窗口坐标对不上；
- 用 Win32 `GetClientRect` 确认客户区，不要看外框尺寸；
- 游戏重启后窗口可能重新居中，需要重跑 resize helper；
- 直播画面里不要出现 HUD、控制台、聊天软件或浏览器标签。

## 7. 隐私检查

- 截图只截游戏窗口，不要截整个桌面；
- 不要展示 API Key、Cookie、后台配置、Qoder 登录信息；
- 日志里的观众昵称属于个人信息，发到 GitHub 前要打码或删除；
- 录像/截图里如果出现直播间 ID、房间号、私信，先确认是否愿意公开；
- 本仓库不包含任何真实配置、日志、存档或凭据。

## 8. 一个推荐的场景布局

```text
┌────────────────────────────────────────────┐
│                                            │
│              Stardew Valley                │
│                1920×1080                   │
│                                            │
│  ┌──────────────────────┐                  │
│  │ 弹幕  观众：…         │                  │
│  │ 肥鱼  回复…           │                  │
│  └──────────────────────┘                  │
└────────────────────────────────────────────┘
```

- 字幕在左下，避免挡人物和工具栏；
- Live2D 皮套如果和游戏同屏，放右下或右上，不要压字幕；
- 游戏声音、TTS、BGM 做侧链/闪避，动作语音不要盖住弹幕回复。
